# i-wli.github.io

Personal homepage: one static page, no build step.

- `index.html`: all content, with anchor navigation
- `style.css`: layout and light/dark theme (IBM Plex via Google Fonts)
- `404.html`: not-found page
- `files/`: slides linked from the page
- `images/`: portrait and favicon

Preview locally:

```bash
python3 -m http.server 8000
```
