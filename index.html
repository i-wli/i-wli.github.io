My PhD

My PhD asked how twisting two atomically thin semiconductors (transition-metal dichalcogenides) changes the way they interact with light: which optical transitions are allowed, and how excitons respond to magnetic fields [provisional: so twist angle can serve as a knob for designing light-based and quantum devices]. Capturing this needs spin-orbit coupling and lattice relaxation in moiré supercells far too large for routine DFT, so I extended existing electronic-structure codes, put machine learning inside physical models, and made moiré-scale modelling fast.

GitHub

0.15 s1.3M-atom supercell

Builds commensurate moiré supercells for twisted van der Waals bilayers, with moiré analysis and an MLIP workflow for relaxation and fine-tuning.

Role: Sole developer.

  • Coincidence-lattice search over Hermite-normal-form sublattices that preserves the moiré wave vectors, up to higher order, rather than strain alone; a polar decomposition separates each layer's rotation from its strain.
  • Vectorized construction builds a 1.3M-atom supercell in 0.15 s (~4,000× faster); optional JAX backend for GPU.
  • MLIP workflow: MACE-MP-0 relaxation and fine-tuning; inexpensive FF labels test whether small cells capture moiré local environments, and fixed acceptance criteria set a go/no-go decision and DFT budget before any DFT is spent.
  • Interfaces: CLI, Gradio GUI and Python API.
  • Relevant publication: W. Li, T. Brumme, T. Heine. npj 2D Mater Appl 8, 43 (2024)
